# Project Nexon - Tithi Reminder Service

A web application that allows users to subscribe to receive reminders for specific Hindu calendar dates (Tithis) from 2024 to 2030.

## Features

- Browse and select Tithis from 2024 to 2030
- Subscribe with email to receive reminders
- Spam protection with reCAPTCHA and honeypot
- Responsive design for all devices

## Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Netlify Functions
- Database: Not specified in current implementation
- Security: Google reCAPTCHA v3

## Development

1. Clone the repository
2. Open index.html in your browser for local development
3. Deploy to Netlify or similar service for production
